# AgentOS

中文 | [English](README_EN.md)

**AgentOS** 是一款运行在 iOS 越狱环境上的端侧多模态自主执行智能体系统（All-in-One 一体化插件）。

它深度集成了底层设备控制服务（MCP Server）、端侧 PaddleOCR 神经模型推理引擎与交互式悬浮思考面板，彻底摆脱了传统自动化对电脑连接与物理像素坐标的依赖。

它彻底摆脱了传统自动化工具对电脑连接（USB/WiFi ADB）与死板物理坐标（Pixel Coordinates）的依赖，通过全局悬浮窗交互，支持**「观察式无感录制 -> 大模型语义提炼 -> 结构化配方持久化 -> 运行时动态定位自主执行」**全闭环。

---

## 🌟 核心特性

- 📱 **脱离电脑，端侧自闭环**：通过本地回环网络直接驱动底层设备控制服务，模型推理与手机界面操作完全在 iPhone 上独立完成。
- 👁️ **观察式无感录制（Observation-Only Recording）**：
  - 录制时仅观察界面变化，不挂钩或拦截用户底层触控事件。
  - 基于 iOS 系统无障碍树（AXTree）与端侧 PaddleOCR 神经模型实时提取页面文本指纹与可点击候选，自动切分操作步骤。
- 🧠 **大模型语义配方提炼（Semantic Distillation）**：
  - 自动提炼任务的入口步骤、前置条件、循环体逻辑、轮次结束标志、退出条件与异常规则。
  - **彻底告别像素坐标**：配方仅包含语义意图与可见文本锚点，天然免疫按钮微调、界面缩放、机型差异以及选项随机乱序。
- 💡 **动态胶囊状态机与触感反馈**：
  - **空闲态（Idle）**：青绿微光边框，显示极简 `AI` 字样。
  - **运行中（Running）**：天蓝边框与文字透明度平滑呼吸脉冲光晕，折叠后清晰传达 Agent 正在后台思考与操作。
  - **完成态（Done）**：变更为翡翠绿背景并显示 `✓ 完成`，同时触发 iOS 系统成功触感震动（Taptic Feedback），3 秒后平滑复原。
  - **中断/异常态（Stopped / Error）**：变更为警示橙背景并显示 `! 停止` 或 `! 异常`，伴随警告震动反馈。
  - **执行自折叠**：点击技能运行后浮窗自动收拢，绝不遮挡下层应用操作视野。
- 🚀 **整装一体化架构（All-in-One Package）**：
  - **安装仅需一个包**：彻底告别双包分离时代！底层 MCP 控制服务、端侧 PaddleOCR 神经推理模型与 AgentOS 悬浮面板深度聚合于同一个 deb，用户只需一次安装即可获得完整闭环体验。
  - **设置入口全局统一**：系统「设置」中统一收拢至「AgentOS」唯一入口，底层服务（端口配置、服务启停、调试日志）无缝内嵌为二级子面板，彻底净化系统设置列表。
- ⚡ **抽屉式技能中心与自定义轮次（Custom Rounds & Safe Stepper）**：
  - 点击「⚡ 技能库」平滑唤出垂直全景抽屉，长技能名完整展示零截断。
  - **自定义轮次与快捷步进**：点击技能进入详情，支持直接输入自定义目标轮数（如 100 轮），并配有 `[-10]` / `[+10]` 快捷步进按钮。
  - **动态步数配额保障（Dynamic Step Budgeting）**：系统根据任务循环体特征自动换算并分配安全步数（突破原 100 步硬上限），跑大轮次任务不被中途打断。
  - **反死循环与界面停滞熔断（Circuit Breakers）**：连续 3 次相同操作无响应或连续 4 次画面无变化时，自动触发安全熔断保护，防止后台无限空转与烧耗 Token。
  - **剪贴板秒级静默导入**：点击「+ 导入」零弹窗秒级入库，支持微信中文全角引号与聊天前缀自动清洗，杜绝 SpringBoard 假死。
- 💾 **结构化技能持久化（Skill Store）**：
  - 技能以标准 XML plist 格式保存在本地存储区（`/var/mobile/Media/ios-deb/skills/`），不受插件升级覆盖影响，便于备份与跨设备迁移。
  - 自动记录技能版本递增、历史执行次数与成功率统计并在浮窗上实时展示。
- 🛡️ **单任务隔离安全模型**：
  - 采用 One-Shot 离散执行机制，用户点一个技能就仅跑该技能，运行结束立即彻底停运，绝不会隐式串连跑下一个任务。

## 📦 支持环境与构建说明

### 运行环境
- 已越狱 iOS 设备（iOS 13.0 - iOS 18.x）
- 兼容越狱环境：
  - **RootHide** (`iphoneos-arm64e`)
  - **Rootless** (`iphoneos-arm64`)
  - **Rootful** (`iphoneos-arm`)

### 编译构建（以 RootHide 为例）

确保本机已配置 Theos 环境：

```bash
# 赋予构建脚本执行权限
chmod +x build_roothide.sh

# 执行打包
./build_roothide.sh
```

构建成功后，将在 `packages/` 目录下生成类似 `com.witchan.ios-deb_2.0.0_iphoneos-arm64e.deb` 安装包。

### 设备安装与部署

可直接推送到越狱设备并通过 `dpkg` 安装：

```bash
dpkg -i com.witchan.ios-deb_2.0.0_iphoneos-arm64e.deb
killall -9 SpringBoard
```

## 📖 快速上手

1. **配置大模型**：
   - 打开 iOS 系统「设置」->「AgentOS」面板。
   - 填入 OpenAI 兼容的 API 接口地址、模型名称与 API Key（Key 本地存储，传输全程自动脱敏）。
2. **录制一个新任务**：
   - 屏幕上点击「AI」悬浮球展开 AgentOS 面板。
   - 点击右侧「● 录制」，面板自动折叠。
   - 正常进行你的目标业务操作（例如在备忘录新建清单，或在学习类小程序中做 2-3 道选择题）。
   - 再次点击悬浮球并点击「■ 完成」。
   - 检查大模型生成的技能规约草稿，确认无误后点击「保存」。
3. **自主重跑**：
   - 展开面板，点击刚才保存生成的技能 Chip。
   - AgentOS 将自动折叠并点亮呼吸灯，根据界面实时呈现的文本与题目，全自动完成后续轮次操作！
